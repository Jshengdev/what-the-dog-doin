# what-the-dog-doin

A multi-app AI agent, and the receipts for what it did.

Built for the Multi-App AI Agent Hackathon (hosted by Lemma and Comma Capital), Sunday 2026-09-13, virtual. The brief: build one useful, multi-step AI agent, connect it to at least three external apps, show how you know it works.

## Status

Pre-build. The agent is defined in `docs/SCOPE-LOCK.md` (open).
